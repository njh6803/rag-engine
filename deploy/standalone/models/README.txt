모델 폴더

이 폴더에 임베딩 서버가 쓰는 모델을 둔다. 임베딩 서버가 이 폴더 안의 models/embedding을 /data로 붙이고,
리랭커를 켜는 설치는 models/reranker를 리랭커의 /data로 붙인다. 묶음에는 두 하위 폴더가 들어 있지 않다.
첫 시작 전에 아래 명령으로 만들어 uid 10001에게 준다.

  mkdir -p models/embedding
  sudo chown -R 10001:10001 models

리랭커를 켜는 설치는 README.md 9절에 따라 models/reranker도 만들고 같은 소유를 다시 준다.

폴더를 미리 만들지 않으면 Docker가 root의 폴더로 만들어, uid 10001로 도는 임베딩 서버가 모델을 쓰지 못하고
Permission denied로 끝난다.

첫 시작은 모델을 인터넷에서 내려받는다. 임베딩 모델(BAAI/bge-m3)은 약 2.2GiB이고, 개발 PC(Windows, Docker Desktop)에서 409초가
걸렸다. 느린 네트워크에서는 더 걸리므로 띄우는 명령은 1800초까지 기다린다.

  docker compose up -d --wait --wait-timeout 1800

모델이 이미 든 폴더로 두 번째부터 시작하면 내려받지 않고 건강해지는 대로 명령이 돌아온다.

시험한 리비전과 받은 리비전

  시험한 리비전: BAAI/bge-m3 의 5617a9f61b028005a4858fdac845db406aefb181
  받은 리비전 읽기: cat models/embedding/models--BAAI--bge-m3/refs/main

리비전은 고정하지 않는다. 첫 시작이 그때의 최신을 받으므로 시험한 리비전과 다를 수 있다.

폐쇄망으로 옮기기

바깥으로 나가는 길이 없는 서버는 인터넷이 되는 기계에서 위의 띄우는 명령을 한 번 성공으로 끝낸 뒤
(임베딩 서버가 건강해진 뒤) models 폴더를 통째로 복사해 옮긴다. 소유(10001:10001)도 서버에서 다시
맞춘다. 내려받다 끊긴 폴더를 옮기면 폐쇄망의 임베딩 서버가 빠진 파일을 받으러 나가다 이름을 풀지 못해
멈출 수 있고, 그러면 네트워크 문제처럼 보인다(재지 않은 어림이다). 모델 폴더를 묶고 푸는 명령(tar)과 이미지를 옮기는 법은 README.md 12절에 있다.
