인증서 폴더

이 폴더에 프록시가 쓰는 인증서와 키를 둔다. 프록시는 아래 두 파일을 이 이름 그대로 읽는다.

  fullchain.pem   인증서. 중간 인증서가 있으면 인증서 뒤에 이어 붙인다.
  privkey.pem     키

사내 인증 기관이나 공인 기관이 발급한 인증서도 같은 이름으로 두면 된다. 인증서를 만드는 명령(시험 삼아
띄울 때 쓰는 스스로 서명한 인증서)은 한 단계 위 폴더의 README.md 3-2절에 있다.

키 파일의 소유와 권한은 아래처럼 맞춘다.

  sudo chown root:101 tls/privkey.pem
  sudo chmod 640 tls/privkey.pem

프록시 컨테이너는 uid 101로 돈다. root만 읽는 키(root:root, 0600)는 프록시가 읽지 못해 프록시가
시작에서 종료 1로 끝난다. 키의 주인은 root로 두고, 그룹 101에 읽기만 연다(0640).

인증서를 새로 받으면 같은 이름으로 이 폴더에 덮어쓰고 새 키 파일에도 위의 두 명령을 다시 친다. 그런 다음
README.md 10절의 두 명령(nginx -t -c, nginx -s reload -c)으로 프록시가 새 파일을 읽게 한다.

이 폴더는 compose가 프록시에 읽기 전용으로 얹는다. 인증서와 키는 저장소나 이미지에 넣지 않는다.
