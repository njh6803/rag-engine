# 07: 지금 동기화로 새 파일과 바뀐 파일 넣기

**What to build:** 운영자가 가져오는 원천에 "지금 동기화"를 부르면 작업자가 폴더의 목록을 받아 새 파일과 바뀐 파일을 문서로 넣고, 그 문서가 검색에 나온다. 바뀌지 않은 파일은 다시 읽지 않는다. 동기화마다 무엇이 시작시켜 어떻게 끝났고 몇 건을 넣었는지가 동기화 기록에 남고, 수집 정책(제외 패턴, 형식, 크기)에 걸린 파일은 문서가 되지 않고 사유별 개수로만 남는다. 동기화 작업은 밀려 있는 색인 작업보다 먼저 꺼내진다. 끊긴 공유 폴더의 읽기는 작업자의 자리를 끝없이 잡지 않는다. 이 티켓은 아직 아무것도 지우지 않는다(지움 반영은 08)(스토리 14, 15, 16, 18, 21의 지금 동기화, 23, 25, 26, 28, 29, 38).

**Blocked by:** 02 (건너뜀), 06 (가져오는 원천 만들기)
