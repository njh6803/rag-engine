# 03: `migrate`와 기본 레코드, 색인 판 요소, 테스트 템플릿 데이터베이스

**What to build:** 운영자가 `rag-engine migrate`를 치면 스키마가 오르고 기본 원천·그룹·지식베이스와 첫 현재 색인 판(HNSW 색인 포함)이 설정값으로 생긴다. 설정을 바꾸고 다시 치면 지식베이스가 새 값을 들고, 끝점만 바뀐 것은 재색인 없이 판에 옮겨진다. 시험은 이 상태를 템플릿 데이터베이스로 복제해 쓴다.

**Blocked by:** 02 (계약)

**Status:** ready-for-agent

**01이 넘긴 것:** 테스트 서버 하나(컨테이너 `rag-engine-test-postgres-1`, 포트 55432)를 워크트리와 세션 전부가 함께 쓰고 러너는 컨테이너를 내리지 않는다(`tools/run_checks.py` 독스트링). 그래서 세션 픽스처가 만드는 템플릿 데이터베이스와 복제본의 이름은 세션(프로세스)마다 달라야 하고(예: 이름에 `uuid4` 토막), 세션이 끝나면 지운다. pytest-xdist 작업자(러너는 `-n`으로 나눠 돈다)마다 세션 픽스처가 한 번씩 돌므로 작업자마다 템플릿을 따로 만든다. `RAG_TEST_DATABASE_URL`의 스킴은 `postgresql://`(psycopg 직접 접속용)이라 SQLAlchemy 엔진에는 `postgresql+psycopg://`로 바꿔 쓴다. 판정 픽스처는 `tests/conftest.py`의 `database_url`이다.

- [ ] 설정 객체(pydantic-settings)가 명세 "설정" 절의 `RAG_*`를 모두 읽는다. 필수 셋이 없으면 시작하지 않고, `RAG_JOB_BACKOFF_BASE_SECONDS`는 실수를 받는다.
- [ ] 엔진(`hide_parameters=True`)과 PostgreSQL 작업 단위가 명세 "포트 열셋과 그 값" 절대로 돈다(예외 없이 나가면 커밋, 예외면 롤백, 속성들이 한 연결의 한 트랜잭션을 공유). 이 티켓은 속성 `catalog`와 `index`(판의 HNSW 부분 색인을 만드는 `VectorIndex`)를 두고, `documents`·`jobs`는 05가, 조각 쓰기와 검색 질의는 07이 더한다. Windows에서는 Selector 이벤트 루프를 고른다(ADR 0011).
- [ ] `Catalog` 어댑터가 원천·그룹·지식베이스·색인 판 레코드를 맡고, 판의 HNSW 부분 색인은 `VectorIndex` 어댑터가 만든다(명세 "포트 열셋과 그 값" 절의 표와 포트 대응).
- [ ] 색인 판 요소를 계산하는 함수가 하나 있다(스키마 판, 임베딩 모델과 차원, 청킹 설정 해시(전략 이름·상한·겹침·전략 구현 판·문장 분리기 판), 토크나이저 판). `migrate`, 재색인 필요 판정과 재색인 시작(14)이 모두 이 함수를 쓴다. 문장 분리기 판과 토크나이저 판의 kiwipiepy·kiwipiepy_model 판도 여기서 읽는다. 해시와 토크나이저 판에 드는 코드 상수 둘(구조 우선 전략의 구현 판, 키워드 규칙의 판)도 이 함수 곁에 한 자리로 두고, 06의 청킹·키워드는 그 이름을 쓴다(06은 이 티켓 뒤에 돈다).
- [ ] `migrate`가 `alembic upgrade head` 뒤 기본 레코드를 보장한다(명세 "관리 명령" 절). 지식베이스 행을 `FOR UPDATE`로 잠근 뒤(없으면 만든 뒤 잠근다) 쓰고, 현재 판이 없으면 첫 판을 `current`로 만들며 그 판의 HNSW 부분 색인을 커밋 직전에 만든다(명세 데이터 모델 절의 DDL 항목). 멱등이다.
- [ ] 다시 돌면 지식베이스 설정을 환경 변수 값으로 고치고, 임베딩 모델·차원이 같고 끝점만 다른 살아 있는 판(건설 중인 판 포함)의 끝점을 고친다. 차원이 2,000을 넘으면 종료 코드 1이고 지식베이스 행을 만들지도 고치지도 않는다.
- [ ] 어댑터 시험: 작업 단위가 예외 없이 나가면 커밋하고 예외로 나가면 롤백하며, 이 티켓의 두 속성(`catalog`, `index`)이 한 트랜잭션에 든다. 05가 나머지 둘을 더하며 이 시험을 넓힌다.
- [ ] 시험: `migrate`의 멱등, 설정 변경 뒤 판 요소가 현재 판과 달라짐(관리 API의 `reindex_needed` 표시는 14), 끝점만 바뀐 설정(`Catalog` 어댑터로 직접 만든 건설 중인 판의 끝점도 고쳐진다), 2,000을 넘는 차원의 거부, 첫 판의 HNSW 색인이 카탈로그에 있음(벡터 질의가 그 색인을 쓰는지는 07이 EXPLAIN으로 본다).
- [ ] 세션 픽스처가 템플릿 데이터베이스에 alembic과 기본 레코드 보장을 한 번 돌리고, 시험마다 템플릿에서 복제한 데이터베이스를 쓰고 지운다(명세 "테스트 데이터베이스와 이미지 판" 절).
- [ ] 검사 넷이 초록이다.
