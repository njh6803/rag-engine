# backup-upgrade: 색인, 원본 문서, 데이터베이스를 명령 하나로 백업하고 복원하며, 판 올림 때 다시 색인해야 하는지 알린다
**슬라이스:** 2
**Blocked by:** source-sync

색인, 원본 문서, 데이터베이스(원천 설정과 암호화한 연결 정보 포함)를 명령 하나로 백업하고 복원한다. 원천에서 지운 문서가 백업에는 남으므로, 복원한 뒤에는 정리 작업을 한 번 돌려 삭제를 다시 반영한다. 색인 형식에 판을 붙여, 판 올림 때 옛 판의 색인을 새 판이 읽는지, 다시 색인해야 하는지를 알린다.

수락: 백업을 새 VM에 복원하면 같은 질의에 같은 조각이 나오고, 옛 판의 색인으로 새 판을 띄우는 판 올림 시험이 통과한다.
