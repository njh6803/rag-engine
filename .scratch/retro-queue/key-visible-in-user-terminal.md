# key-visible-in-user-terminal: 사용자 터미널 화면에 판정기 API 키의 글자가 보여 세션이 그 화면을 읽을 때 키가 대화에 실렸다

**상태:** 열림
**어디로:** `docs/agents/`나 `.claude/rules/tools.md`의 한 줄 또는 `tools/search_eval.py judge`가 키를 `.env`에서 받는 길(사용자가 비밀을 터미널에 치지 않고 `.env` 파일이나 보안 입력 프롬프트로 넣게 한다). 자리는 반영하는 chore가 정한다
**승인:** 자체 승인 2026-11-17, 1회차(더하는 것이라 다섯 번째에 반영한다. 손상인지는 사용자가 키를 교체했는지에 달려 있고 이 세션은 모른다), 일지 2026-11-17-1101-search-eval-13-first-judge-run.md, ADR 불필요

티켓 13에서 이 세션의 `.env` 읽기를 권한 판정이 거부해 사용자가 키를 넣은 환경에서 `judge`를 직접 돌렸다. 이 세션이 터미널 패널을 읽는 도구로 출력을 확인하다가 화면에 키의 글자가 보인 것을 알았다. 이 세션은 그 값을 답이나 커밋에 옮기지 않았고(커밋 대상에서 `sk-ant`와 `api03`을 `git grep`으로 찾아 0건이었다) 사용자에게 키를 교체하라고 안내했다. 대화 기록에 키가 실렸는지는 확인할 수 없다.
