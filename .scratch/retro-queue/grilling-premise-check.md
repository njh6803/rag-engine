# grilling-premise-check: 선택지 설명의 전제를 제품 그림(ADR·PRD)에 대 보지 않아 사용자가 바로잡았다

**상태:** 열림
**어디로:** `.claude/skills/grilling/SKILL.md`의 "올리기 전" 문단에 한 줄(설명에 넣는 사실을 코드·판정자뿐 아니라 ADR과 `docs/PRD.md`가 그린 제품의 자리에도 대 본다. 내부 부품을 설치처의 기존 것에 붙이는 장면을 전제로 두지 않는다)
**승인:** 자체 승인 2026-11-09, 1회차(더하는 것이라 다섯 번째에 반영한다), 일지 2026-11-09-2125-core-design.md, ADR 불필요

core 설계 인터뷰 라운드 16의 최소 PostgreSQL 판 질문에서 선택지 설명에 "2026년 설치처의 PostgreSQL이 18일 가능성은 낮음"이라고 적었다. PostgreSQL은 이 제품이 동봉하는 데이터베이스(ADR 0002)라 그 장면이 없었고, 사용자가 라운드 17에서 바로잡았다. 일지의 "에이전트가 번복하거나 고친 것" 절.
