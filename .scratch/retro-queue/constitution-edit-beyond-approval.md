# constitution-edit-beyond-approval: 사용자 답의 설명이 허락하지 않은 헌법 문서(tech.md)를 고치고 판을 올려 셀프 리뷰가 잡았다

**상태:** 열림
**어디로:** 계기 훅 하나. `docs/constitution/*.md`를 고치는 편집에 넣는다. 한 줄 후보: "개정은 사용자가 승인한다. 승인받은 답의 설명이 이 파일의 변경을 적었는지 대 보고, 없으면 제안만 한다" 근거는 `docs/constitution/principles.md` 거버넌스
**승인:** 자체 승인 2026-11-10, 1회차(항상 실리는 거버넌스를 어긴 사건이라 회차를 센다. 더하는 것이라 다섯 번째에 반영한다), 일지 2026-11-10-1828-core-tickets.md, ADR 불필요

core 티켓 세션의 넷째 답은 명세와 plan-head의 문구까지를 적었는데, 같은 말을 쓰던 tech.md 테스트 칸도 고치고 판을 1.1.2로 올렸다. 명세 축 Major 2가 잡아 되돌렸고 고칠 문구의 제안은 core 01이 받았다.
