# extract-asks-tool: 설계 인터뷰 일지의 인용(라벨·설명·되물음 원문)을 세션 기록에서 뽑는 스크립트가 저장소에 없어 세션마다 다시 쓴다

**상태:** 열림
**어디로:** `tools/extract_asks.py`(세션 기록 JSONL에서 `AskUserQuestion` 호출의 질문·선택지 라벨·설명과 사용자의 답, 직접 입력 원문을 질문 단위로 낸다)와 `.claude/skills/grilling/SKILL.md` "옮길 때" 문단의 포인터 한 줄
**승인:** 자체 승인 2026-11-09, 2회차(더하는 것이라 다섯 번째에 반영한다), 일지 2026-11-09-2125-core-design.md, 2026-11-12-2108-search-eval-design.md(2회차), ADR 불필요

grilling은 답을 일지로 옮길 때 라벨과 함께 고른 선택지의 설명을 글자 그대로 옮기라고 한다. core 설계 인터뷰(19라운드, 68개 질문)의 일지를 쓰며 스크래치패드에 추출 스크립트를 두 판 썼다. 첫 판은 직접 입력 답을 호출 전체의 답으로 붙여 틀렸고, 질문 문장 위치로 답 구간을 자르는 둘째 판으로 고쳤다(거부된 호출은 뺐다). 세션이 끝나면 스크립트가 사라진다.
