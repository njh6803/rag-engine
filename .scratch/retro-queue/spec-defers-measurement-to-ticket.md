# spec-defers-measurement-to-ticket: 새 결정을 낳을 수 있는 측정 둘을 명세가 재지 않고 티켓의 손 확인으로 넘겨 셀프 리뷰가 잡았다

**상태:** 열림
**어디로:** `.claude/skills/to-spec/SKILL.md`(명세를 닫기 전에 본문에서 티켓에 넘긴 확인을 Grep으로 찾아, 3단계가 그 자리에서 재라고 한 측정인지 대 보는 단계를 둔다)
**승인:** 자체 승인 2026-11-21, 1회차(이미 있는 지침을 어긴 사건이라 회차를 센다. 더하는 것이라 다섯 번째에 반영한다), 일지 2026-11-21-1358-source-sync-spec.md, ADR 불필요

source-sync 명세가 설치 안내에 적을 명령(`docker compose restart server worker`)이 통하는지와 설치 폴더에 `sources/`가 없을 때의 동작을 티켓이 손으로 확인하게 적었다. 셀프 리뷰 명세 축이 Major로 냈고, `mount-propagation` 프로브에 단계 둘을 더해 쟀다.
