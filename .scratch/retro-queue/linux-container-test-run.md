# linux-container-test-run: 윈도 PC에서 리눅스 갈래를 확인하는 컨테이너 실행을 세션이 즉석 스크립트로 짓는다

**상태:** 열림
**어디로:** `tools/linux_check.py`(새 도구. 작업 트리를 `.venv`와 `.git` 없이 복사하는 컨테이너 안에서 `uv sync --frozen` 뒤 인자로 받은 시험을 돌리고 마지막 줄들을 찍는다)
**승인:** 자체 승인 2026-11-11, 1회차(더하는 것이라 다섯 번째에 반영한다), 일지 2026-11-11-1328-core-08-parsers-isolation.md, ADR 불필요

core 08 구현 세션이 리눅스에서만 서는 시험 갈래(`RLIMIT_AS`, 절반만 보내고 멈추는 파서)를 이 PC에서 재려고 컨테이너 실행 명령을 두 번 직접 지었다. 한 번은 `tar --exclude=.git`이 들어 있어 워크트리 가드가 거절해 스크립트 파일로 옮겨 다시 쳤다. `.claude/rules/tests.md`는 이 PC의 초록이 리눅스의 증거가 아니라고 하고, 07 일지는 리눅스 갈래를 이 PC에서 재지 못했다고 적었으며, 08에서 컨테이너가 상한을 바꾼 뒤 깨진 시험 하나를 윈도 부분 실행보다 먼저 잡았다. 잃은 데이터는 없고 세션의 시간과 컨텍스트를 썼다. 새 도구는 그 지침을 한 번에 칠 수 있는 명령으로 바꾸는 것이다.
