# adr-draft-drops-option-conditions: 고른 선택지의 설명과 합의 요약에 있던 조건을 ADR 초안이 빠뜨려 승인 뒤에 더했다

**상태:** 열림
**어디로:** `.claude/skills/grill-with-docs/SKILL.md` 산출물 단계에 한 줄(ADR 초안을 올리기 전에 합의 요약의 번호와 고른 선택지 설명의 조건마다, 그것을 받는 ADR 문장이나 넘긴 자리를 하나씩 대 본다. `.claude/skills/grilling/SKILL.md`의 "옮길 때"가 이미 있는 지침이다)
**승인:** 자체 승인 2026-11-12, 1회차(이미 있는 지침을 어긴 사건이라 회차를 센다. 더하는 것이라 다섯 번째에 반영한다), 일지 2026-11-12-2108-search-eval-design.md, ADR 불필요

search-eval 설계 세션이 ADR 초안 셋을 승인받은 뒤에 초안이 빠뜨린 조건을 두 번에 걸쳐 더했다. 파일로 쓰며 스스로 대 보아 찾은 것이 아홉이고(ADR 0017에 넷, 0018에 넷, 0019에 하나), 셀프 리뷰 명세 축이 더 찾은 것이 Major 하나와 Minor 둘이다. Major는 ADR 0019에서 범위를 가르는 말("이 저장소의 평가에서는", "설치처에서는")이 빠져 CI의 동작을 적은 두 문장이 서로 부딪친 것이다. 결정이 바뀐 것은 없지만, 사용자가 승인한 초안과 병합되는 ADR의 글이 달라졌다.
