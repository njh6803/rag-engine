# last-ticket-end-line-unchecked: 기능의 마지막 열린 티켓을 닫는 구현 세션이 기능 계획의 끝 줄을 적을 계기가 없어 병합 직전에야 알았다

**상태:** 열림
**어디로:** `tools/check_ticket.py`나 `tests/test_plan_status.py`에 검사 하나(`**슬라이스:**` 줄이 있는 기능의 마지막 열린 티켓을 `done`으로 바꾸는 변경이 그 기능 계획에 `**끝:**` 줄을 더하지 않았으면 실패한다)
**승인:** 자체 승인 2026-11-17, 1회차(더하는 것이라 다섯 번째에 반영한다), 일지 2026-11-17-1101-search-eval-13-first-judge-run.md, ADR 불필요

search-eval 티켓 13은 같은 기능의 마지막 열린 티켓이었다. 이 세션의 할 일 목록에 끝 줄을 적는 단계가 없었고(`docs/agents/issue-tracker.md`의 "끝 줄을 적는 때"), 기능 계획에 끝 줄이 없다는 것을 병합을 앞두고 dev의 나란한 티켓 16, 17, 20이 모두 `done`이 된 것을 보고서야 알았다. 끝 줄이 빠진 채 병합되면 출시 PR의 계기(`next-session`의 출시 PR 줄)가 켜지지 않는다. 세션이 알아챈 덕에 잃은 것은 없다. 지침이 시키는 일이 사람이나 세션의 기억에 달려 있어 검사로 올린다.
