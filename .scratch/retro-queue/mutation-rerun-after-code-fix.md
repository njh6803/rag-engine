# mutation-rerun-after-code-fix: 코드를 고친 뒤 변이 표를 `--check`만 하면 `expect = "red"`가 거짓이 된 변이를 놓친다

**상태:** 열림
**어디로:** `.claude/skills/implement/SKILL.md`(변이 단계의 "코드를 옮기거나 고쳤으면 그 코드를 겨누던 변이 파일을 `--check`로 본다" 문장에, 고친 코드가 변이가 겨누던 갈래를 대신 받게 되면 그 변이를 실제로 돌려 빨강을 다시 본다는 것을 더한다)
**승인:** 자체 승인 2026-11-12, 1회차(더하는 것이라 다섯 번째에 반영한다), 일지 2026-11-12-1116-core-13-lease-worker-process.md, ADR 불필요

core 13에서 `_keep_lease`에 `except Exception`을 더하자, `except TransientFailure`를 다른 예외로 바꾸는 변이(표의 17번)가 더 이상 시험을 빨갛게 만들지 못했다. 새 분기가 일시 실패까지 받아 연장을 계속하기 때문이다. 그 고침 뒤에 표를 `--check`만 해서(원문이 한 번씩 있는지만 본다) 놓쳤고, 푸시한 뒤 CodeRabbit이 짚었다. 자동 검사로 옮기기는 어렵다. 변이를 실제로 돌려야 알 수 있고, 표 하나가 수 분에서 수십 분 걸려 커밋 훅에 넣을 수 없다.
