# token-expiry-test-load-margin: 만료 토큰 시험이 만료 시각을 지금+2초로 두어 검사 러너의 부하에서 발급 요청이 늦게 닿으면 422로 빨갛다

**상태:** 열림
**어디로:** `tests/server/test_authentication.py`(만료 시험의 여유를 부하와 무관하게 한다. 만료 시각을 넉넉히 두고 만료 뒤의 401은 시계를 주입하거나 토큰 행의 만료 시각을 지나게 고쳐 본다. 끝이 열린 결함 종류(부하에서만 빨간 시간 시험)의 첫 사례라 셋째 사례부터는 사례를 고치지 않고 종류를 없애는 길을 고른다)
**승인:** 자체 승인 2026-11-11, 1회차(고침이라 문턱 없이 반영한다. 면제 PR이 `tests/`를 못 고쳐 대기열에 둔다), 일지 2026-11-11-0929-core-get-document-text-window.md, ADR 불필요

`test_만료된_토큰은_401_토큰_만료이고_만료_전에는_받는다`가 `expires_at`을 `datetime.now(UTC) + 2초`로 두고 발급 API를 부른다. 검사 러너가 pytest를 작업자 여럿으로 돌리며 `run-hooks` 검사도 함께 도는 부하에서 요청이 서버의 검증(`src/rag_engine/app/tokens.py`의 만료 시각이 이미 지났다)에 닿기 전에 2초가 지나 422를 받았다. 같은 시험을 따로 돌리면 초록이고, 같은 브랜치의 앞 커밋에서는 같은 검사가 초록이었다. 코드를 손대지 않은 문서 PR에서 났다.
