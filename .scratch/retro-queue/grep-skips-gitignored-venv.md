# grep-skips-gitignored-venv: Grep 도구로 `.venv` 폴더를 검색하면 일치가 있어도 "일치 없음"이 나와 서드파티 소스의 사실을 거짓으로 적게 한다

**상태:** 열림
**어디로:** `CLAUDE.md` 환경 함정 절의 한 줄(설치된 서드파티 소스는 Grep에 파일 경로를 직접 주거나 `uv run python -c`로 모듈 위치를 찍어 연다. 폴더를 가리키면 빈 결과로 끝난다)
**승인:** 자체 승인 2026-11-14, 1회차(더하는 것이라 다섯 번째에 반영한다), 일지 2026-11-14-2147-search-eval-12-relevance-judge-claude.md, ADR 불필요

SDK가 쓰는 로거 이름을 확인하려고 `.venv/Lib/site-packages/anthropic` 폴더를 Grep하자, `httpx2`가 든 파일(`_utils/_logs.py`)이 있는데도 일치 없음이 나왔다. 같은 파일을 직접 가리키면 일치가 나왔다. 폴더 검색이 `.gitignore`를 따라 `.venv`를 건너뛰는 것으로 보이지만(ripgrep의 기본 동작) 이 세션이 그 원인을 따로 재지는 않았다. 빈 결과를 "없다"로 읽으면 근거를 거짓으로 적게 된다. 이번에는 셀프 리뷰가 낸 로거 이름 지적을 확인하던 중에 만났고, 파일을 직접 열어 바로잡았다. 잃은 것은 호출 몇 번이다.
