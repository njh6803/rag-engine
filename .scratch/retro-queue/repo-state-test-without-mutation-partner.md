# repo-state-test-without-mutation-partner: 저장소 상태를 재는 시험을 위반을 잡는 짝 없이 써서 셀프 리뷰가 Major로 잡았다

**상태:** 열림
**어디로:** `tools/check_instructions.py`에 검사 하나(같은 시험 파일에 `test_이_저장소의_`로 시작하는 함수가 있으면 위반을 잡는다는 이름이 든 함수도 있는지 본다. `.claude/rules/tests.md`의 저장소 상태 시험 규칙을 기계가 판정하게 한다)
**승인:** 자체 승인 2026-11-20, 1회차(구현 때 실리는 규칙을 어겨 리뷰가 잡은 사건이라 회차를 센다. 더하는 것이라 다섯 번째에 반영한다), 일지 2026-11-20-1455-release-image-04-install-guide-walks-operator.md, ADR 불필요

release-image 04에서 안내와 묶음의 다른 파일을 맞대는 시험 파일(`tests/tools/test_deploy_guide.py`)을 처음 쓸 때 저장소 상태 시험 여럿(인증서 이름, 프록시 주 설정, 환경 변수 칸, 소유, 리비전, 대응표 등)을 변이 짝 없이 세웠다. `.claude/rules/tests.md`는 저장소 상태를 보는 검사마다 지금 통과함을 재는 시험과 위반을 잡는 변이 시험을 하나씩 두라고 한다. 셀프 리뷰 표준 축이 이를 Major로 짚어 한 칸만 바꾼 사본으로 같은 검사가 걸리는지 보는 변이 시험으로 고쳤다. 판정에 쓸 기계 규칙은 이름 짝(`test_이_저장소의_…`과 `…을_잡는다`)이라 거짓 양성이 적을 것으로 본다. 쓰이는 이름 꼴이 바뀌면 이 검사가 조용히 비게 되므로, 반영할 때 훑은 범위가 비면 실패하는 단언도 함께 둔다.
