# rename-sweep-misses-forms: 이름을 바꾸는 PR이 옛 이름의 꼴을 손으로 짠 정규식으로 훑어, 놓친 꼴을 셀프 리뷰가 잡고 선택 화면의 수도 실제와 어긋난다

**상태:** 열림
**어디로:** `tools/`의 훑기 도구 하나(옛 이름과 새 이름을 받아 파일별 잔존을 찍고, 새 이름의 받침에 맞지 않는 조사를 함께 찍는다)
**승인:** 자체 승인 2026-11-18, 2회차(더하는 것이라 다섯 번째에 반영한다), 일지 2026-11-18-1817-glossary-harness-small-names.md, 2026-11-18-2230-glossary-root-branch-merge-back.md, ADR 불필요

`glossary-harness-small-names`는 옛 이름 셋을 Grep 정규식으로 훑어 바꿨다. 정규식이 좁아 시험 독스트링의 "문턱을 넘은 항목"을 놓쳤고, 새 이름 "결함"의 받침에 맞지 않는 "결함라" 둘을 남겼으며, 일지가 처음 적은 잔존 수(30개 파일, 일지 23)도 틀렸다. 셀프 리뷰 두 축이 모두 잡았다. 선택 화면에 올린 바뀌는 곳의 수도 실제와 어긋났다(화면 10개 파일, 실제 12개). 이름 바꾸기 PR이 `glossary-plain-names-left`에 아직 여럿 남았으므로 같은 훑기가 되풀이된다.
