3. 점검 주기

3.1 일일 점검

일일 점검은 매일 작업 시작 전에 실시한다. 점검 항목은 전원부 이상음, 냉각팬 작동, 표시등 상태 세 가지다. 이상이 있으면 장비를 멈추고 관리자에게 알린다.

3.2 월간 점검

조각 41

월간 점검에서는 배전반 온도, 비상 발전기 시동, 소화 설비 압력을 확인한다.

항목기준조치
배전반 온도60℃ 이하넘으면 부하를 줄이고 보고
비상 발전기 시동10초 안에 시동늦으면 정비 요청
소화 설비 압력0.7MPa 이상낮으면 충전 요청

13쪽

3.3 연간 점검

연간 점검은 외부 공인 기관에 맡긴다. 점검 결과서는 5년 동안 보관한다.

4. 기록

점검자는 점검을 마친 날 점검 일지에 결과를 적고 서명한다.
