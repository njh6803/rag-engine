# admin: 관리자 페이지 v0. 현황, 원천, 문서, 검색 시험 화면에서 문서를 올리고 지우며 잘 찾아지는지 확인한다
**슬라이스:** 2
**Blocked by:** source-sync

킥오프 입력 5절의 "제품 0.1에서 화면으로 만들 것"(현황, 원천, 문서, 검색 시험)을 만든다. 문서를 제때 올리고 지울 수단이 없으면 색인이 낡은 문서로 답하기 때문이다. core와 source-sync의 관리 API 위에 서고, MCP 도구로는 열지 않는다. 사내 로그인(OIDC)으로 할지, 운영자 계정 하나로 시작할지는 설계 인터뷰가 정한다. 화면의 디자인은 이 저장소가 스스로 정한다. 관리자 페이지의 이미지를 release-image의 판 태그 규칙에 더하고, 단독 compose에서는 같은 포트의 경로 하나로 연다. 설계 인터뷰의 입력은 킥오프 입력 5절이다.

수락: 브라우저에서 표본 문서를 올려 상태가 바뀌는 것을 보고, 문서의 조각 목록을 열어 보며, 원천의 지금 동기화와 작업 기록이 보이고, 검색 시험의 결과가 같은 질문에 대한 MCP 검색 결과와 같으며, 문서를 지운 뒤에는 그 문서의 조각이 검색에 나오지 않는 e2e가 통과한다.
