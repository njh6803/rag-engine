# db-source: SQL 커넥터. 운영자가 쓴 질의와 매핑으로 데이터베이스에 든 글과 그 첨부를 문서로 수집한다
**슬라이스:** 3
**Blocked by:** source-sync

킥오프 입력 4절의 "SQL 커넥터: 세 층"대로 짓는다. 연결 문자열로 드라이버를 고르고, 운영자가 적은 질의와 매핑 설정(ID, 본문 템플릿, 메타데이터 칼럼과 형식, 증분의 기준, 삭제, 첨부 칼럼과 자식 질의)으로 데이터베이스에 든 글과 그 첨부를 문서로 가져온다. 원천에는 읽기 전용 계정으로 붙는다. 변환 플러그인의 예시 하나(본문의 HTML 정리)를 함께 낸다. 재배포할 수 없는 드라이버는 설치 환경이 볼륨으로 넣는 절차를 안내에 적는다. 관리자 페이지에 질의 결과 몇 행이 어떤 문서와 첨부가 되는지 미리 보는 화면을 둔다. 구조화 데이터는 이 커넥터로 가져오지 않는다(킥오프 입력 4절). 설계 인터뷰 전에 대상 DBMS별로 드라이버, 재배포 조건, ODBC 대안을 표로 정리한다(킥오프 입력 7절의 4).

수락: 본문 칼럼 여럿, 메타데이터 칼럼 여럿, 1:N 첨부 표(첨부는 파일 경로)를 가진 표본 게시판을 PostgreSQL과 다른 DBMS 하나에서 원천으로 수집하고, 행과 첨부를 더하고 고치고 지우면 다음 실행 뒤 검색 결과가 따라 바뀌며, 변환 플러그인 예시를 켜면 본문의 HTML이 정리된 채 색인된다.
