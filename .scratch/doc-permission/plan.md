# doc-permission: 문서 묶음별 접근 그룹으로 검색을 거르고, MCP `_meta`에 주체가 없는 요청은 거부한다
**슬라이스:** 3
**Blocked by:** admin

실행의 주체는 MCP 요청의 `_meta`로 받는다. 그 형식은 MCP의 `_meta`에 주체를 싣는 범용 형식이고, 이 서버의 계약 문서에 적는다. 주체에서 그룹을 찾는 길(요청에 그룹이 실려 오는지, 이 서버의 사용자와 그룹 표인지)은 설계 인터뷰가 정한다. 문서의 접근 그룹을 어디서 정할지도 같은 인터뷰가 고른다: 모두 공개, 관리자가 묶음이나 원천에 지정, 원천의 권한(공유 폴더의 ACL 등)을 가져오기다. 원천의 권한을 가져오면 원천에서 권한이 바뀐 뒤 반영되기까지 시간차가 생기므로, 그 반영 주기도 정한다. 검색 결과의 조각에는 접근 그룹 칸이 실리므로, 클라이언트도 같은 권한을 답과 기록에 쓸 수 있다. 주체가 오지 않은 요청은 거부한다(기본은 닫힘). 시험은 `_meta`에 주체를 실어 보내는 시험용 MCP 클라이언트로 한다.

수락: 그룹이 다른 주체 둘이 같은 질문을 하면 각자 볼 수 있는 문서의 조각만 나오고, 주체가 없는 요청은 거부되는 계약 시험이 통과한다.
