# 19: 공개 데이터셋의 참고 측정

**What to build:** 공개 데이터셋(allganize)을 이 명세의 묶음 형식으로 바꿔 로컬에서 평가를 돌리고, 그 데이터셋의 질문(스토리 19가 말하는 사람이 만든 질문)으로 한 번 더 확인한 숫자를 프로브로 남긴다(스토리 19, ADR 0018). 따로 준비할 질문은 없다. PDF와 질문은 커밋하지 않는다.

**Blocked by:** 06 (쪽으로 적은 기대 근거와 `figure` 유형), 07 (`--records off`)

**Status:** ready-for-agent

- [ ] 데이터셋의 이름과 이용 조건을 원문(데이터셋의 카드와 라이선스 파일)으로 확인하고 프로브 README에 확인한 자리와 날짜를 적는다. 명세 세션은 원문으로 확인하지 않았다. 조건이 로컬 측정과 숫자의 커밋을 허락하지 않으면 멈춰 사용자에게 묻는다.
- [ ] 데이터셋을 내려받아 묶음 형식으로 바꾸는 스크립트를 `.scratch/search-eval/probes/`에 둔다. 기대 근거는 문서와 쪽 번호(`kind: page`)로 적고, 그림 유형 문항은 `figure`로 표시한다. 내려받은 파일은 저장소 밖의 폴더에 두고 커밋하지 않는다(`.gitignore`로 막히는지 본다).
- [ ] 바꾼 묶음이 커밋하는 공공 문서 묶음의 규모에서 온 규칙(문서 파일의 합 30MB 이하)에 걸리면 **멈춰**, 그 규칙을 커밋하지 않는 참고 묶음에도 걸지 사용자에게 묻는다(명세는 정하지 않았다). 답에 따라 `validate`를 고치거나 묶음을 줄인다.
- [ ] 바꾼 묶음이 `validate`를 지나고, `rag_eval` 머리의 새 데이터베이스에 `index`와 `run --through fused --records off`가 돈다. 리랭크 기록이 없으므로 전체 실행은 리랭커 끝점이 있을 때만 돌린다.
- [ ] 저장소에는 스크립트와 보고서의 숫자(`report.json`과 `report.md`. 글이 없다)만 커밋하고, 돌린 명령과 장치, 걸린 시간을 프로브 README 표에 적는다.
- [ ] 검사 넷이 초록이다.
