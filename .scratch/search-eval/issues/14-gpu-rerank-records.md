# 14: GPU로 리랭크 기록을 만들고 장치 사이의 값 차를 잰다

**What to build:** 개발 PC의 GPU로 TEI GPU 이미지를 띄워 임베딩과 리랭크의 처리량을 프로브로 남기고, 같은 장치에서 다시 계산한 값과 CPU·GPU 사이의 값이 얼마나 다른지 잰 뒤, 공공 문서 묶음의 전체 실행으로 `records/rerank.jsonl`을 만들어 커밋한다(명세 "전체 게이트와 리랭커"). 전체 게이트, 점수 분포, 리랭커 실험이 이 기록에 기댄다. 명세가 기다리던 NVIDIA 드라이버 갱신은 2026-11-13에 끝났다(티켓 세션이 `nvidia-smi`로 621.24를 손으로 봤다).

**Blocked by:** 10 (질문과 임베딩 기록)

**Status:** ready-for-agent

- [ ] TEI GPU 이미지(`turing-1.9.4`)가 명세 세션의 우회(`cuda>=12.9` 검사 끄기, 상위 호환 라이브러리 폴더 가리기) 없이 `--gpus all`로 뜨고 모델을 올리는지 본다. 뜨지 않으면 서버 로그를 남기고 멈춰 사용자에게 넘긴다(명세 세션의 실패 로그는 `.scratch/search-eval/probes/tei-cpu/gpu_turing_start_server_log.txt`).
- [ ] GPU 이미지를 띄운 방법과 임베딩·리랭크의 처리량을 `.scratch/search-eval/probes/`에 프로브(스크립트, 출력, README 표의 행)로 남긴다. 선례는 같은 폴더의 `tei-cpu/`다.
- [ ] 값의 차(명세의 값의 차 항목): 같은 글 32개의 임베딩과 같은 쌍 32개의 리랭크 점수를 CPU 이미지로 두 번, GPU 이미지로 한 번 계산해 벡터의 코사인 유사도의 최솟값과 점수 차의 최댓값을 프로브로 남긴다. 어느 쪽이든 코사인 0.999 아래이거나 점수 차가 0.01을 넘으면 **멈춰** 사용자에게 다시 묻는다. 티켓 세션의 명세 검토가 손으로 본 CPU 임베딩의 반복(JSON으로 받은 값이 `==`로 같았다)도 이 프로브로 옮겨 다시 잰다.
- [ ] 리랭크 기록: 리랭커 TEI를 GPU로 띄우고 공공 문서 묶음에 `run --through rerank --records write`를 돌려 `rerank.jsonl`을 만든다. 질의 임베딩 파일이 같은 바이트로 남는지 본다. 기록 만들기가 2시간을 넘으면 **멈춰** 사용자에게 다시 묻는다. `records.json`에 장치(GPU)와 TEI의 판이 적힌다.
- [ ] `rerank.jsonl`을 커밋하고 `validate`가 통과한다. 리랭커 끝점 없이 `run --through rerank`(기록 방식 `read`)가 기록에 없는 쌍 없이 끝나는 것을 본다.
- [ ] 걸린 시간과 장치를 `## Comments`와 프로브 README에 적는다.
- [ ] 검사 넷이 초록이다.
