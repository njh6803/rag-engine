# 14: GPU로 리랭크 기록을 만들고 장치 사이의 값 차를 잰다

**What to build:** 개발 PC의 GPU로 TEI GPU 이미지를 띄워 임베딩과 리랭크의 처리량을 프로브로 남기고, 같은 장치에서 다시 계산한 값과 CPU·GPU 사이의 값이 얼마나 다른지 잰 뒤, 공공 문서 묶음의 전체 실행으로 `records/rerank.jsonl`을 만들어 커밋한다(명세 "전체 게이트와 리랭커"). 전체 게이트, 점수 분포, 리랭커 실험이 이 기록에 기댄다. 명세가 기다리던 NVIDIA 드라이버 갱신은 2026-11-13에 끝났다(티켓 세션이 `nvidia-smi`로 621.24를 손으로 봤다).

## Comments

- 07의 한계(PR 직전 리뷰가 짚었다): `--records write`는 요청 지문과 TEI 판이 같으면 장치가 달라도 기록의 옛 값을 옮기고, 다시 쓰는 항목의 `device`는 이번 `--tei-device`로 적는다(`inference_records.py`의 `_usable_entry`와 `_rendered`를 읽었다). 장치를 판정에 넣으면 값의 차를 재는 이 티켓의 몫(명세 "값의 차" 항목)과 겹쳐 07이 정하지 않았다. 그래서 이 티켓이 GPU로 `run --records write`를 돌 때 CPU로 만든 질의 임베딩 파일의 값이 그대로 옮겨져 `records.json`의 그 항목이 `gpu`로 적힐 수 있다. 값이 섞인 항목에 장치를 적기 전에 그 항목의 기록 파일을 지우고 다시 만들지 정한다.
  - 이 티켓의 결과: 섞인 값은 없다. 조각 임베딩(2178)과 질의 임베딩(310)은 티켓 10이 GPU 이미지로 만든 값이고, 이 티켓이 새로 계산한 값은 질의 하나(`labr-01`)와 리랭크 점수 15,476쌍뿐이며 모두 같은 GPU 이미지(`turing-1.9.4`)로 만들었다. 그래서 세 항목 모두 `device`가 `gpu`, `tei_version`이 `1.9.4`다.
- 2026-11-15 이 티켓을 구현했다(구현 세션, GPU는 GTX 1660 Ti, 드라이버 621.24, 이미지 `turing-1.9.4`, `--max-batch-tokens 4096`, 모델 캐시는 외부 볼륨 `search-eval-tei-probe-data`). 띄우기 전에 `docker ps`로 다른 TEI가 없는 것을 봤다.
  - `labr-01`: 사람 질문 문구를 "수습을 시작한 날부터 3개월 동안은"으로 고쳤고 사용자가 검수해 확정한 문구라 PR 본문에서 알린다. GPU로 `run --through fused --records write --tei-device gpu`를 다시 돌려 질의 임베딩 키가 하나 빠지고 하나 더해졌으며(310개 가운데) 나머지 309개의 값은 바이트까지 그대로였다. 조각 임베딩 파일은 바뀌지 않았다. 이 순서를 지켜 리랭크 기록의 키가 새 문구로 만들어졌다.
  - 우회 없이 뜬다: `--gpus all`과 compose의 GPU 예약만으로 임베딩 TEI와 리랭커 TEI가 둘 다 떴고 모델을 GPU로 올렸다(`.scratch/search-eval/probes/tei-gpu/gpu_embed_start_server_log.txt`, `gpu_rerank_start_server_log.txt`). 드라이버 621.24로 올린 뒤의 결과다. 띄운 방법은 `tei-gpu/compose-gpu.yml`이다.
  - 처리량(프로브 `tei-gpu/*_throughput_gpu_out.txt`, 평가 묶음의 글로 잰 것): 조각 임베딩 192개에 120.2초(1.60개/초, 조각마다 약 471 토큰), 질의 임베딩은 중앙값 77ms, 리랭크 96쌍에 60.8초(1.58쌍/초)였다. 이 값으로 15,000쌍을 어림하면 약 158분이라 2시간을 넘는다.
  - 값의 차(프로브 `tei-gpu/device_diff.py`, 출력 `device_diff_out.txt`. 글 32개와 쌍 32개): 임베딩에서 CPU 두 번(컨테이너를 다시 띄운 사이)은 값이 완전히 같았고(코사인 1.0), GPU 두 번은 같지 않았다(코사인 최솟값 0.99998064, 최대 절대 차 6.6e-4).
