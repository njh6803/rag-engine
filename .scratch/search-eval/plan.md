# search-eval: 평가 세트로 검색의 상위 k개 적중률을 재고, 기준치 아래로 떨어지면 CI가 실패한다
**슬라이스:** 2
**Blocked by:** core

평가 세트(질문과 기대 근거)로 상위 k개 적중률을 잰다. LLM 없이 검색만 재므로, 청킹, 임베딩 모델, 리랭커를 바꿀 때마다 돌려 검색 품질이 떨어지는 것을 잡는다. 공개 시연(core, search-eval, release-image)의 한 축이다.

수락: 공개 문서 묶음의 평가 세트로 적중률 보고서가 나오고, 정한 기준치 아래로 떨어지면 CI가 실패한다.
