원천을 만들면 문서가 검색 서버에 자동으로 들어옵니다. 서버 기계의 폴더를 `.env`의 `RAG_ENGINE_SOURCES_DIR`로 읽기 전용으로 붙이고, 그 아래 하위 폴더마다 원천을 만들면 PDF, DOCX, HWPX 문서가 검색에 오릅니다. 관리 API(`/api/v1/admin/sources`)로 원천을 만들고 연결을 확인하고, 지금 동기화하거나 일정(cron)을 붙이며, 동기화 기록으로 결과를 봅니다. 폴더에서 더하고 고치고 지운 문서는 다음 동기화 뒤 검색에 반영되고, 지운 문서와 원천은 `RAG_DELETED_RETENTION_DAYS`일 동안 되살릴 수 있습니다.
