rag-engine은 MCP를 쓰는 어떤 클라이언트에서도 쓸 수 있는 설치형 문서 검색 서버입니다. 문서를 넣어 색인해 두면, 클라이언트가 MCP로 질문과 맞는 문서 조각을 찾아 갑니다. 서버는 찾는 일까지만 하고 답을 만들지는 않습니다. 0.1.0은 첫 정식 릴리스이고(그 출시 후보 0.1.0-rc.N도 같은 소개를 싣습니다), 아래 두 기능이 처음으로 함께 실립니다.

**문서 검색 서버(core).** 서버는 PDF, DOCX, HWPX 문서(글자가 든 파일)를 받아 조각으로 나누고 색인합니다. 문서는 관리 명령이나 수집 API로 넣습니다. 클라이언트는 서버의 MCP 끝점에서 지식베이스 목록, 검색, 문서 정보 조회 세 가지 읽기 도구를 씁니다. 검색 결과에는 조각이 나온 위치와 문서의 갱신일이 붙습니다. MCP로는 읽기만 열려 있어서, 문서 속 지시에 속은 에이전트가 문서를 지우거나 바꾸는 일은 구조로 막힙니다. MCP 끝점은 토큰이 있어야 열리고, 문서를 넣는 중에도 검색은 계속 답합니다.

**검색 품질 평가(search-eval).** 문서를 조각으로 나누는 방식이나 임베딩 모델(글을 숫자로 바꾸는 모델)을 바꿀 때마다 검색 품질이 떨어지지 않았는지 숫자로 재는 평가 도구입니다. 개발 중에 돌리는 도구라, 평가를 돌리는 명령은 설치한 서버에 들어 있지 않고 운영자가 따로 할 일도 없습니다. 조각 크기와 리랭커 사용 같은 기본값을 이 평가로 정했습니다. 리랭커(검색 결과를 다시 정렬하는 모델 서버)는 검색이 느려지는 만큼 기본 설치에서 꺼져 있고, 켜는 설치만 설치 안내의 절차대로 켭니다. 리랭커를 켠 지식베이스에서는 검색에 최소 점수를 줘서 점수가 낮은 조각을 결과에서 뺄 수 있습니다.

설치는 배포 파일 묶음을 풀고 그 안의 설치 안내를 따릅니다. 이 릴리스가 처음이라 업그레이드할 앞 릴리스는 없고, 데이터베이스 구조를 만드는 마이그레이션은 설치 안내대로 `docker compose up`으로 띄울 때마다 서버보다 먼저 돕니다.
