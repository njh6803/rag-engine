# rag-engine 헌법

세 파일로 나뉜다. 로드 시점이 다르기 때문이다.

- [principles.md](principles.md): 원칙 일곱과 거버넌스. `CLAUDE.md`가 임포트해 항상 실린다.
- [tech.md](tech.md): 언어, 도구, 의존성. 의존성을 더하거나 스택을 바꿀 때 읽는다.
- [operations.md](operations.md): 검증, 가드레일, 브랜치와 병합, 리뷰 파이프라인, 이슈, 설치처 정보, 문서 위치. 커밋·병합·리뷰·트래커를 만질 때 읽는다.

디렉터리별 규칙은 헌법이 아니라 `.claude/rules/*.md`에 있고 해당 파일을 Read 도구로 열 때만 실린다. 현재 트리는 루트 `README.md`, 미래 배치와 첫 슬라이스의 범위는 `.scratch/plan.md`에 있다. 판을 올린 까닭은 그 변경의 ADR 이력이나 일지에 적는다. 아래 판 줄 곁에는 형제 브랜치가 먼저 매겨 비워 둔 판의 문장이 한 줄에 하나씩 남고, 그 브랜치가 판을 가져가면 그 문장을 지운다.
