# 검색 질문의 내용을 남기지 않고 지연 시간만 남긴다

검색 질문에는 개인 정보나 내부 사정 같은 민감한 내용이 들어갈 수 있고, 이 서버는 문서를 밖으로 보낼 수 없는 조직에 설치된다. 그래서 이 서버는 질문의 내용을 로그, 진단 묶음, 변경 기록, 지표 어디에도 남기지 않고 검색 지연 시간만 남긴다. 대화 기록과 질문 기록, 답에 대한 오류 신고는 클라이언트의 몫이다(PRD). 검색 품질은 운영 질문이 아니라 평가 세트(search-eval)로 잰다.

## Consequences

- 관리자 페이지의 현황은 최근 검색 지연만 보이고, 검색 시험 화면의 질문도 저장하지 않는다.
- "어떤 질문에 답이 나빴는지"는 이 서버에서 알 수 없다. 운영자는 클라이언트 쪽에서 신고된 답과 인용 문서를 보고, 문서를 이 서버의 관리자 페이지에서 고친다.
